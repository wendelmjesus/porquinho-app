# 🐷 Porquinho

**Porquinho** is a personal finance desktop application built with Python and PySide6.

The project is currently under development and was created to explore desktop application development, UI/UX design, software organization, and personal finance management.

## Features

- 📊 Financial dashboard
- 💳 Income and expense management
- ➕ Transaction creation
- 🔍 Transaction search and filtering
- 🗑️ Transaction removal
- 🏷️ Transaction categories

## Tech Stack

- **Python**
- **PySide6**
- **Qt / QSS**

## Status

🚧 **Work in progress**

Porquinho is still in its early development stage. Features, interface elements, and project structure may change as development continues.
